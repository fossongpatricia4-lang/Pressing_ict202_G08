# Pressing Groupe 8

Application web de pressing developpee avec React, TypeScript et Vite.

## Fonctionnalites

- Inscription, connexion et deconnexion des entreprises de pressing
- Ajout de vetements avec image, client, prix, date de retrait et notes
- Statuts: propre, sale, en lavage, loue, retouche
- Disponibilite pour la location
- Listes separees des vetements laves et non laves avec images
- Parametres via menu trois barres: langue, theme, logo, a propos
- Sauvegarde locale dans IndexedDB
- Recherche, filtres, statistiques, retards, export et import JSON

## Lancement

Installe Node.js avec npm, puis lance:

```bash
npm install
npm run dev
```

Pour generer la version de production:

```bash
npm run build
```
